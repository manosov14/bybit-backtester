# Telegram bot

## Назначение
Дать пользователю простой интерфейс для запуска backtest и получения результата прямо в Telegram.

## Объём
- поддерживать команды `/backtest`, `/strategy`, `/status` и `/help`
- разбирать и проверять аргументы команд
- запускать соответствующий application service
- показывать статус выполнения и итоговый report
- возвращать понятные сообщения об ошибках

## Что не входит
- web interface
- authentication и роли пользователей
- произвольная настройка нескольких strategies
- выполнение реальных торговых операций

## Входные данные
- Telegram update с командой и аргументами
- для `/backtest`: symbol, timeframe и lookback period
- результат или ошибка от application service

## Выходные данные
- подтверждение запуска backtest
- итоговая statistics в читаемом текстовом формате
- описание active strategy
- service status и доступность data
- usage help и сообщения о неверных аргументах

## Правила
- `/backtest BTCUSDT 1h 90d` является базовым пользовательским сценарием
- bot layer не содержит логику strategy, market data или расчёта statistics
- ошибки пользователя отличаются от внутренних ошибок service
- ответы остаются короткими и помещаются в ограничения Telegram
- команды и формат аргументов одинаково описываются в `/help` и обработчиках

## Пограничные случаи
- команда неизвестна или отправлена без обязательных аргументов
- symbol, timeframe или lookback period имеют неверный формат
- для периода нет market data
- backtest завершается без trades
- внешний service временно недоступен

## Критерии приёмки
- все четыре команды отвечают по назначению
- корректный `/backtest` запускает полный application flow
- пользователь получает итоговую statistics или понятную причину отказа
- обработчики Telegram не выполняют прямые запросы к Bybit или PostgreSQL

## Тесты
- unit tests для parsing и validation каждой команды
- тесты формата успешных ответов и сообщений об ошибках
- сценарий `/backtest BTCUSDT 1h 90d` с подменённым application service
- сценарии неизвестной команды и неверных аргументов
- smoke test полного Telegram flow
